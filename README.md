# LiftLog

LiftLog is a beginner-friendly, mobile-first workout tracker MVP built with Next.js, TypeScript, Tailwind CSS, and localStorage.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Main workflow

1. Open the app.
2. Tap **Start Workout**.
3. Add an exercise, such as `Barbell Bench Press`.
4. Log sets and check them complete.
5. Tap **Finish Workout**.
6. Return later and use the exercise suggestion to see previous PR context.
